# AGENTS.md — Web Pembelajaran Kimia

## 1. Teknologi
- Gunakan React + Vite.
- Gunakan komponen fungsional React.

## 2. Penyimpanan
- Gunakan localStorage untuk menyimpan data latihan dan progres belajar secara anonim.
- Jangan menyimpan identitas pribadi siswa yang tidak diperlukan.

## 3. Struktur
- Simpan komponen yang dapat digunakan kembali di src/components/.
- Gunakan App.jsx untuk menyusun komponen utama halaman.
- Pertahankan struktur proyek React + Vite yang sudah tersedia.

## 4. Bahasa
- Gunakan bahasa Indonesia yang baku, jelas, dan komunikatif.
- Sesuaikan penjelasan dengan tingkat pemahaman siswa SMA kelas XI.

## 5. Notasi Kimia
- Pastikan rumus, indeks, muatan ion, simbol, dan persamaan kimia ditulis dengan benar.
- Contoh notasi: H₂SO₄, Ca²⁺, OH⁻, dan H₃O⁺.
- Pastikan penjelasan materi dan jawaban kuis sesuai dengan konsep kimia yang benar.

## 6. Aturan Pengembangan
- Baca PRD.md sebelum mengembangkan atau mengubah fitur.
- Ikuti kebutuhan yang tertulis dalam PRD.md.
- Jangan menambahkan fitur di luar PRD tanpa persetujuan.
- Jangan menghapus kode yang sudah berfungsi tanpa alasan yang jelas.

## 7. Pemeriksaan
- Pastikan website dapat dijalankan dengan npm run dev.
- Periksa tampilan dan fungsi website melalui browser.
- Periksa error pada terminal dan browser Console.
- Jangan menyatakan pengujian berhasil jika belum dilakukan.
